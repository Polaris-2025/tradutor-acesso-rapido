# Tradutor de Acesso Rápido 🚀

Um motor de tradução e processamento de fluxo leve, ultra-otimizado e de baixo consumo de recursos, desenvolvido em Node.js para execução local de alta performance (Edge Computing).

## 💡 Sobre o Projeto
A maioria das aplicações modernas depende de servidores pesados na nuvem para tarefas simples, gerando latência e dependência excessiva de rede. Este projeto utiliza a arquitetura de *Streams* e *Buffers* do Node.js para processar dados de forma contínua e eficiente, mantendo o consumo de memória extremamente reduzido.

## 🛠️ Tecnologias Utilizadas
- **Node.js** (*Streams* & *Buffers*)
- **JavaScript (ES6+)**
- Arquitetura reativa orientada a eventos.

## ⚙️ Como Executar
Certifica-te de que tens o Node.js instalado no teu computador. No terminal, na pasta raiz do projeto, executa:

```bash
node tradutor.js
